安裝說明

NextCalc

macOS Telegram 桌面應用程式，含計算機風格鎖定畫面。本文件說明安裝、首次開啟、升級，以及建議的通知設定。

版本
1.3.1
架構
macOS arm64（Apple Silicon）
簽名
ad-hoc（無開發者簽名）
01

安裝

把 app 從磁碟映像檔搬進「應用程式」資料夾。

  1. 雙擊 NextCalc-1.3.1-arm64.dmg 掛載磁碟映像檔。
  2. 視窗開啟後，把左側的 NextCalc 圖示拖到右側的 Applications（應用程式）捷徑上。
  3. 複製完成後，在 Finder 側邊欄按下 NextCalc 磁碟旁的退出符號，或在桌面上對它按右鍵選「退出」。
  4. DMG 檔案本身可以刪除，安裝好的 app 位於 /Applications/NextCalc.app。
命令列替代做法 也可以用終端機完成掛載與複製： 
hdiutil attach NextCalc-1.3.1-arm64.dmg
cp -R /Volumes/NextCalc*/NextCalc.app /Applications/
hdiutil detach /Volumes/NextCalc*
02

首次開啟

此版本為 ad-hoc 無簽名建置，第一次開啟需要手動放行一次。

直接雙擊會看到「無法打開，因為它來自未識別的開發者」或「無法驗證開發者」的提示。這是 macOS Gatekeeper 對未經 Apple 公證的 app 的預設阻擋，放行一次之後就不會再出現。

  1. 在 /Applications 內對 NextCalc 按右鍵（或按住 Control 點一下），選擇「打開」。
  2. 在跳出的對話框再按一次「打開」。
  3. 若對話框沒有出現「打開」選項，前往「系統設定 → 隱私權與安全性」，在下方找到被阻擋的 NextCalc，按「仍要打開」。
命令列替代做法 直接移除隔離屬性，之後即可正常雙擊開啟： 
xattr -d com.apple.quarantine /Applications/NextCalc.app
若顯示 No such xattr，表示該屬性本來就不存在，可以忽略。
注意 右鍵「打開」與 xattr 兩種做法選一種即可，不需要同時執行。
03

升級

新版 DMG 直接覆蓋舊 app，資料與登入狀態都保留。

  1. 先完全結束 NextCalc（選單列 NextCalc → 結束，或 Command + Q）。
  2. 掛載新版 DMG，把 NextCalc 拖進「應用程式」資料夾。
  3. 系統詢問時選擇「取代」，覆蓋舊版本。

使用者資料存放在 app 套件之外，覆蓋安裝不會受影響：

~/Library/Application Support/next-calc
  • Telegram 登入狀態與對話快取保留，升級後不需重新登入。
  • 密碼與偏好設定（config.json）保留。
  • 不需要、也不建議先刪除舊版 app 再安裝。
注意 資料重設功能會刪除上述資料目錄並重設密碼，與升級無關，請勿混用。
04

通知設定建議

兩處各設一次，讓通知在解鎖時有用、在鎖定時不洩漏內容。

macOS 系統設定

系統設定 → 通知 → NextCalc 把「顯示預覽」設為「解鎖時」。螢幕解鎖時才顯示發訊者與訊息內容，鎖定畫面自動隱藏。

Telegram Web 端

Settings → Notifications → Message Preview 開啟此選項，通知才會帶出發訊者與訊息摘要；關閉時只會收到一則沒有內容的提示。

說明 兩處是串聯關係：Telegram 端決定通知裡有沒有內容，macOS 端決定這些內容什麼時候可以顯示在螢幕上。兩者都設好，才會是「解鎖看得到、鎖屏看不到」。
